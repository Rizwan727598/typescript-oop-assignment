# TypeScript & OOP Practice

Practice project built for the B8A1 TypeScript & OOP module — covers core types, generics, type narrowing, OOP, and async Promises.

## Contents

- **`solutions.ts`** — All 8 problem solutions in one file.
- **`type-narrowing.md`** — Blog post on type narrowing with `typeof`, `instanceof`, and `in`.
- **`union-and-intersection-types.md`** — Blog post on combining union and intersection types.

## What's Inside

1. `multiplyValue` — Optional parameter handling.
2. `processInput` — Union types and `typeof` narrowing.
3. `formatCoordinate` — `readonly` tuples.
4. `concatenateArrays` — Generics with rest parameters.
5. `getPopularCourses` — Interfaces and array filtering.
6. `pluckValues` — `keyof` constraints in generics.
7. `Employee` / `Manager` — OOP with access modifiers and inheritance.
8. `validateAgeAsync` — Promises with `resolve` / `reject`.

## Testing

`solutions.ts` contains only declarations and no output statements, so running it directly produces nothing.

To try a function, copy it into a scratch `.ts` file and call it there, or import it after adding an `export` keyword to the declaration you want to use.
